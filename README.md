# Phantom Awards 2026

Fan-made game awards voting site for the **DePhantom தமிழ்** YouTube community.

**Vote:** https://jvn1604.github.io/Phantom-Awards/

- 45 categories, Google sign-in, one vote per category
- Predictions game with a leaderboard, voter badges
- Results sealed until the reveal, then a live reveal and an OBS overlay for streams
- English and Tamil interface, light and dark themes, mobile-first

Built with plain HTML, CSS and JavaScript on GitHub Pages, with [Supabase](https://supabase.com) for sign-in and the database. Setup steps are in [SETUP-GUIDE.md](SETUP-GUIDE.md).

Not affiliated with The Game Awards or any game publisher.
